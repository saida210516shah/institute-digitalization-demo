# Демо-платформа Института цифровизации и инноваций

Статическая русско-казахская учебная платформа с каталогом демонстрационных курсов, уроками, тестами и демо-кабинетом слушателя.

## Возможности

- 8 демонстрационных курсов в 4 тематических направлениях
- Переключение русского и казахского интерфейса
- Фильтры по направлению и целевой аудитории
- Запись на курс, уроки, тесты и отображение учебного прогресса
- Сохранение языка и прогресса в `localStorage` текущего браузера
- Адаптивная вёрстка для компьютеров и телефонов

## Структура

- `dist/` — готовое статическое приложение
- `.openai/hosting.json` — настройки каталога для Sites

Курсы и материалы демонстрационные. Платформа не использует серверную регистрацию, оплату или серверное хранение прогресса.

Для размещения достаточно опубликовать содержимое каталога `dist/` на любом статическом хостинге.
