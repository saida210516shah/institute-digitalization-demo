# Учебная платформа Института цифровизации и инноваций

Статическая русско-казахская учебная платформа: каталог демонстрационных курсов, уроки, тесты, вход по email и паролю и синхронизация прогресса через Supabase.

## Возможности

- 8 демонстрационных курсов в 4 тематических направлениях
- Переключение русского и казахского интерфейса
- Поиск и фильтры по направлению и аудитории
- Регистрация, вход, подтверждение email, сброс и смена пароля через Supabase Auth
- Запись на курсы и синхронизация уроков и результатов тестов между устройствами
- Таблица прогресса с Row Level Security: слушатель может читать и менять только собственные записи
- Адаптивная вёрстка для компьютеров и телефонов

## Подключение Supabase

1. Создайте проект Supabase и откройте его **SQL Editor**.
2. Выполните SQL из `supabase/migrations/0001_learning_progress.sql`.
3. В **Authentication → URL Configuration** укажите адрес сайта в **Site URL** и добавьте адрес сайта в **Redirect URLs**. Для локальной проверки добавьте `http://localhost:4173/**`.
4. В настройках проекта возьмите **Project URL** и **Publishable key** (или legacy `anon` key). Не используйте `service_role`/secret key в браузере или Vercel.
5. В Vercel откройте проект → **Settings → Environment Variables**. Добавьте `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` для Production, Preview и Development.
6. После сохранения переменных запустите новый Production Deployment. Build command `node scripts/build-config.mjs` создаёт клиентскую конфигурацию из публичных переменных окружения.
7. Для отправки ссылок подтверждения и сброса пароля на публичном сайте настройте собственный SMTP в **Authentication → SMTP Settings**. Тестовый почтовый сервис Supabase имеет ограничения на отправку.

Открытый каталог доступен без входа. Регистрация, запись на курс, тесты и кабинет требуют аккаунт. Прогресс гостевого режима, созданный в `localStorage` до подключения авторизации, объединяется с прогрессом аккаунта при первом входе на этом устройстве.

## Локальный запуск

Платформа хранится в `dist/`. Скопируйте `.env.example` в `.env`, заполните публичные `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`, запустите `node scripts/build-config.mjs`, затем раздайте каталог `dist/` локальным статическим сервером. Файл `.env` исключён из Git.

Курсы и материалы демонстрационные. Сайт не принимает оплату и не выдаёт официальные сертификаты.
